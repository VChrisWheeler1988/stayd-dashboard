Action Plan

Step 1 · Unit data

Load a Unit Leaderboard

Drop this week's Unit Leaderboard export. To refresh an existing brand, pick it from the dropdown — the dashboard matches unit names and pre-selects the right one. Market data and notes for that brand are preserved.

Single-metric exports work too. If you export just one column (e.g. Adj. RevPAR) it's detected as a supplement and merged into the matching brand, updating only that metric. Ideally include Adj. RevPAR in the main leaderboard so one file does everything — plain “RevPAR” counts owner-blocked nights and runs lower, so mixing the two across brands isn't apples-to-apples.
Drop the Unit Leaderboard here
or click to choose a file (.xlsx / .csv)
Step 2 · Market stats

Load market / benchmark exports

Drop one file per bedroom size plus an all-bedrooms run for the total picture — you can select them all at once. Each file's bedroom filter, brand, and market are detected automatically.

To get RevPAR gaps, include ADR. In Key Data, build the benchmark with two metrics: Adj. Paid Occ. % and ADR. An occupancy-only export still loads — you'll just see occupancy gaps, and RevPAR will show as unavailable.

Step 3 · Publish

Download & push to GitHub

Bakes every loaded brand, its market data, and this week's snapshot into a fresh index.html.

  1. Open your live dashboard (not an old download) so last week's history carries forward.
  2. Load each brand's leaderboard, then its market exports.
  3. Click Download index.html.
  4. In GitHub → Code tab → + → Upload files → drag it in → Commit changes.
  5. Hard-refresh the live site (Cmd/Ctrl + Shift + R). Live in ~1 minute.
